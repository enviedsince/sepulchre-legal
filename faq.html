Getting started

Set up Sepulchre in your community.

01   What is Sepulchre?

Sepulchre is an all-in-one Discord bot project centered on moderation, ticket management, giveaways, automation, and community tools. The website showcases those features in a unified design.

02   How do I add the bot to my server?

Use the official Add to Discord button once your bot invitation URL has been configured in assets/config.js. You must have permission to manage or add apps to the target Discord server.

03   Can Sepulchre be used on more than one server?

Multi-server operation is part of the project design. Individual guild settings should remain separate; exact rollout and availability depend on the deployed version.

04   Do I need to give the bot Administrator permission?

No — granting Administrator broadly is not recommended. Give it only the permissions each enabled feature genuinely requires, and ensure its role sits appropriately within the server hierarchy.

Features & setup

Common module questions.

01   Can I configure ticket panels?

The planned toolkit includes customizable ticket panels, staff workflows, and transcripts. Features visible in this static website are previews until connected to your bot runtime.

02   Does the bot support giveaways?

The project includes giveaway creation, entry, ending, winner selection, and reroll functionality. Actual command names depend on the installed version.

03   Can I build embeds directly from this website?

Yes. The Embed Builder lets you compose messages, preview a Discord-style embed, add fields, and copy or download JSON. Sending the message to a server requires a separate authenticated integration.

04   Is the dashboard connected to my Discord server?

Not in this download. It is an interactive front-end concept only; toggles change the preview locally and do not send API requests or modify any Discord settings.

Licensing & support

Policies and connection details.

01   How much does Sepulchre cost?

No official pricing was provided for this website build. The Plans page deliberately avoids invented prices. Enter verified licensing information before going public.

02   Where can I get support?

The Support Server link can be activated by entering your real Discord server URL in assets/config.js. Until then, the button explains how to configure it.

03   Where can I read the privacy policy or terms?

Those legal pages need your approved, final policy wording and public URLs before publishing. This preview does not substitute another bot’s policies or pretend policies are already hosted.
